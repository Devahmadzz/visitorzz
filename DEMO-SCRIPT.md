# Five-minute client demo walkthrough

Use the fictional sample records or other invented details. This is a browser-local demonstration, not an official Nigerian Customs Service service. Open the reception page and `/display/` in separate tabs or windows before presenting.

| Time | Walkthrough |
| --- | --- |
| 0:00–0:30 | **Set the context.** Point out the “DEMO VERSION” label and explain that records stay in this browser. Sign in as Receptionist with `reception@demo.ngcs` / `Desk2026!`. Open the customer display in a separate window. |
| 0:30–1:30 | **Register a visitor.** Choose “New check-in”. Enter a fictional Nigerian phone number, name, and address. To demonstrate the returning-visitor lookup, use one of the seeded records, such as Adaeze Nwankwo (`08031204561`); confirm that the returning-visitor badge appears and saved details fill in. Advance to the photo step and capture a webcam image or use image upload. |
| 1:30–2:10 | **Show live display mirroring.** Keep the reception form and customer display side by side. Complete the host, purpose, optional group members, and appointment fields. Point out the visitor details and photo updating on the second screen, along with the NDPA data-privacy notice. |
| 2:10–2:55 | **Assign a tag.** Choose “Assign tag”, use the “Suggest next free tag” shortcut or select a green tag, and review the check-in time and visitor confirmation. Complete the check-in and point out the large tag number on both screens. |
| 2:55–3:35 | **Show the tag board.** Open “Tag board”. Find the newly assigned red tag and show the visitor details. Explain that active tags cannot be reassigned; the Admin can also mark an available tag unavailable or restore it. |
| 3:35–4:15 | **Check out.** Open “Visitors inside”, locate the test visitor, and select “Check out”. Show that the exit is recorded and the tag returns to the available count. Point out the end-of-day panel listing any tags still in use. |
| 4:15–5:00 | **Show reports and close.** Sign out and sign in as Admin with `admin@demo.ngcs` / `Admin2026!`. Open “Reports”, switch between daily and monthly logs, try a date/officer/purpose filter, and show CSV export and print view. Mention the Settings and audit log, then close by reiterating that this demo stores data locally and does not sync between devices. |

Camera permission is requested only when “Start camera” is selected and requires HTTPS or `localhost`; image upload is available as a fallback. Use fictional details only and avoid presenting this demo as an official government service.
